# Epiphany Padfield

Static site. No account, no monthly platform fee. Open `index.html` or serve the folder.

Phone and email are not on the public pages. After a valid enquiry form, the page shows the placeholders in `main.js`: `REVEAL_PHONE_DISPLAY`, `REVEAL_PHONE_TEL` and `REVEAL_EMAIL`. Swap those three when the real number and mailbox should be public. The form does not send email anywhere yet.

Pages: `index.html`, `services.html`, `about.html`, `enquire.html`. Old `delivery.html` and `practice.html` addresses redirect. The theme toggle stores `padfield-theme` in the browser. First visit follows the operating system. Light and dark each have their own palette. Photographs are indicative plant, not records of a contract.

Live site: https://theblackcat94.github.io/epiphany-padfield/

Host the folder on GitHub Pages, Cloudflare Pages, or Netlify’s free static tier. Point the domain at it.

Swap the wordmark if the registered business name is not Padfield. Do not publish a client’s name here unless they have agreed.
