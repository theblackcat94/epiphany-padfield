# Epiphany Padfield

Static site. No account, no monthly platform fee. Open `index.html` or serve the folder.

Enquiry mail goes to the address in `main.js`:

```js
const ENQUIRY_EMAIL = "padfieldepiphany@gmail.com";
```

Change that one line when the business mailbox is ready. Phone number is in the page footers and on `enquire.html`.

Pages: `index.html`, `services.html`, `delivery.html`, `practice.html`, `enquire.html`. The theme toggle stores `padfield-theme` in the browser. First visit follows the operating system. Light and dark each have their own palette. Photographs are indicative plant, not records of a contract.

Live site: https://theblackcat94.github.io/epiphany-padfield/

Host the folder on GitHub Pages, Cloudflare Pages, or Netlify’s free static tier. Point the domain at it. The form opens the visitor’s email app, so there is no form backend to pay for.

Swap the wordmark if the registered business name is not Padfield. Do not publish a client’s name here unless they have agreed.
